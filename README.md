# iris-flower-project
# 🌸 Iris Flower Classification Project

## 📌 Project Overview
This project is a Machine Learning model that predicts the type of Iris flower based on its features like sepal length, sepal width, petal length, and petal width.

## 🌼 Flower Types
- Iris-setosa  
- Iris-versicolor  
- Iris-virginica  

## 📊 Dataset
The dataset used is the famous **Iris dataset** which contains 150 samples of flowers.

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## 🤖 Machine Learning Model
- Random Forest Classifier
- Train/Test Split method
- Accuracy evaluation

## 📈 Steps Performed
1. Loaded dataset
2. Checked data structure
3. Visualized data
4. Split data into train/test
5. Trained model
6. Predicted flower type

## 🎯 Result
The model gives high accuracy (around 90–100%) in predicting flower species.

## 🚀 How to Run
1. Open Google Colab
2. Upload Iris.csv
3. Run all Python cells step by step
4. Train model and test prediction

## ✨ Output Example
Input:
[5.1, 3.5, 1.4, 0.2]

Output:
Iris-setosa
